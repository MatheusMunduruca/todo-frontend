# Todo Frontend

Interface web desenvolvida em **React** para o gerenciamento de tarefas, consumindo a [Todo API](https://github.com/MatheusMunduruca/todo-api).

---

## Tecnologias

- React 18
- React Router DOM
- Axios
- Vite
- CSS Modules

---

## Funcionalidades

- Cadastro e login de usuários
- Autenticação via JWT
- Criação, listagem e exclusão de tarefas
- Atualização de status (Pendente → Em andamento → Concluída)
- Filtro de tarefas por status
- Rotas protegidas (redireciona para login se não autenticado)

---

## Como rodar

### Pré-requisitos

- [Node.js](https://nodejs.org/) 18+
- [Todo API](https://github.com/MatheusMunduruca/todo-api) rodando em `http://localhost:5000`

### Instalação

```bash
npm install
npm run dev
```

Acesse `http://localhost:5173`
